# Practica de Git
## Cambiar Rama:
`git checkout (rama)`

## Crear Rama:
`git checkout -b (nueva-rama)`

## Subir Rama y crear PR:
`git push -u origin (rama)`

## Eliminar Rama:
`git branch -d (rama)`

## Eliminar origenes no remotos:
`git remote prune origin`
